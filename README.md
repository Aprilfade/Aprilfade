### 🏆 Featured Project: EXEsystem

#### 🚀 [智能在线考试与学习管理系统](https://github.com/Aprilfade/EXEsystem)
>  一个功能完整的企业级在线教育平台，集成 AI 智能批改、实时知识对战、智能复习推荐等创新功能。

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/Aprilfade/EXEsystem/blob/master/LICENSE)
[![Spring Boot](https://img.shields.io/badge/Spring%20Boot-3.5.4-brightgreen.svg)](https://spring.io/projects/spring-boot)
[![Vue](https://img.shields.io/badge/Vue-3.5.17-brightgreen.svg)](https://vuejs.org/)
[![GitHub stars](https://img.shields.io/github/stars/Aprilfade/EXEsystem?style=social)](https://github.com/Aprilfade/EXEsystem/stargazers)

**项目亮点**:
* 📚 **65+ 完整技术文档** - 系统化的开发文档、API文档与部署指南
* 🤖 **AI 智能功能** - 支持DeepSeek/Claude/Gemini多AI提供商，智能出题、AI批改、学习分析
* 🎮 **游戏化学习** - 知识竞技场、成就系统、积分商城、段位匹配
* 📊 **智能推荐系统** - 基于考试成绩的课程推荐、协同过滤题目推荐
* 🔐 **企业级安全** - Spring Security + JWT 双重认证，完善的权限管理（RBAC）
* 📈 **AI监控系统** - 完整的API调用监控、成本统计、CSV导出 ⭐v3.06

**技术架构**:
* **后端**: Spring Boot 3.5.4 + Spring Security 6.x + MyBatis Plus 3.5.12
* **前端**: Vue 3.5.17 + TypeScript 5.8.3 + Element Plus 2.10.5 + Vite 7.0.4
* **数据库**: MySQL 8.0 + Redis 7.2
* **部署**: Docker + Docker Compose 一键部署

**核心功能模块** (35个页面 + 68个组件):
* ✅ **AI 智能出题** - 基于文本/知识点自动生成题目，流式响应展示生成过程
* ✅ **AI 批改系统** - 主观题自动评分，智能反馈与错因深度分析
* ✅ **智能推荐引擎** ⭐v3.06
  - 基于考试成绩的课程推荐（分析薄弱科目）
  - 协同过滤算法的题目推荐
  - 智能相关度匹配的课程搜索
* ✅ **AI 监控平台** ⭐v3.06
  - 实时API调用监控和统计
  - Token使用量和成本分析
  - CSV格式日志导出（支持Excel直接打开）
* ✅ **课程学习中心** - 视频播放、章节管理、进度追踪、断点续播
* ✅ **知识对战系统** - 实时 1v1 对战、段位匹配、连击系统
* ✅ **智能复习推荐** - 艾宾浩斯遗忘曲线、薄弱点识别、错题本自动收集
* ✅ **数据可视化** - ECharts 图表、学习报告、成绩分析
* ✅ **权限管理系统** - RBAC 模型、细粒度权限控制、审计日志

**项目规模**:
* **后端**: 32个 Controller + 42个 Service + 37个 Entity + 40个 Mapper
* **前端**: 35个页面 + 68个组件 + 26个 API 模块
* **文档**: 65+ 技术文档 + 完整API文档 + 5个 SQL 脚本
* **API接口**: 25个核心接口，完整的Swagger文档

**最新版本**: v3.06 (2026-03-06)
* 🤖 **AI监控增强** - CSV导出、时间筛选、完整字段导出
* 🎓 **智能课程推荐** - 基于考试成绩分析，个性化推荐薄弱科目课程
* 🔍 **课程搜索优化** - 智能相关度计算，按匹配度排序
* 🐛 **用户认证优化** - SecurityContext集成，获取真实用户ID
* ✨ **登出流程统一** - 教师端和学生端统一跳转体验

**v3.0 重大更新**:
* 🔐 JWT 异常处理优化，防止日志污染
* 🎯 填空题多答案智能匹配（支持单空/多空/中英文逗号通用）
* 📚 AI 练习页面优化（动态科目加载）
